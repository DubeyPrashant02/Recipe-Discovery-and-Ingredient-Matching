
# Ingredient Selection Module

## Team Project
Recipe Discovery & Ingredient Matching

## Assigned Role
Ingredient Selection Module Development

## Description
A React-based ingredient selection module that allows
users to search, select and manage available kitchen
ingredients for recipe discovery.

## Features

- Real-time ingredient search
- Category-based filtering
- Ingredient selection and deselection
- Custom ingredient addition
- Duplicate ingredient prevention
- Selected ingredient counter
- Remove individual ingredients
- Clear all ingredients
- Persistent storage using LocalStorage
- Responsive user interface

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- LocalStorage
- Vite
- Git and GitHub

## Installation

npm install

npm run dev
